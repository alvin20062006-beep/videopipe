隐私政策

生效日期：2026 年 8 月 11 日

VideoPipe 是在用户 Windows 设备上运行的开源应用。VideoPipe Skills 插件只提供安装、使用和故障排查说明，不运行远程服务，也不会由插件开发者接收用户的 ChatGPT 对话。

处理的数据

桌面应用会在本地处理用户主动提交的视频链接、任务状态、临时媒体文件和下载结果。应用不要求创建 VideoPipe 账号，也不要求提供姓名、邮箱、密码或 Cookie。

处理目的

这些数据仅用于解析用户提供的链接、执行用户发起的下载、显示进度、恢复未完成任务以及交付下载结果。

数据接收方

解析链接时，链接来源网站会收到正常的网络请求。部分微信视频号公开分享链接可能发送至第三方解析服务。用户使用 ChatGPT 或 GitHub 时，相应平台会按照各自的隐私政策处理数据。

保存期限

任务记录和下载文件保存在用户设备上，直到用户删除。临时任务文件会在结果交付后由应用清理。插件开发者不维护用户数据数据库。

用户控制

用户可以停止任务、删除本地任务记录和文件，或停止使用并删除 VideoPipe。请勿向问题反馈提交 Cookie、密码、私人链接或下载内容。

联系与更新

隐私问题可以通过 GitHub Issues 提交。政策更新会发布在本页面，并修改生效日期。
